# VocabPro

This repository holds only the built files of **VocabPro**, a free,
offline-capable vocabulary app for Indian competitive exam aspirants (UPSC,
SSC, banking, railways, CAT and state PSC exams).

- Use it on the web: https://vishwanathbite.github.io/vocabpro/
- Get it on Google Play: https://play.google.com/store/apps/details?id=com.literaryrides.vocabpro

The files here are published automatically from a private source repository.
They are not meant to be edited by hand, and pull requests are not accepted.

## Privacy

VocabPro has no accounts and asks for no personal information. Your progress
is stored only on your own device, in the browser's local storage.

The site uses Cloudflare Web Analytics, which counts page views without
cookies. See the privacy policy: https://literaryrides.com/privacy-policy/
